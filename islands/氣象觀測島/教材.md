## 教材內容

### 天氣兩大核心問句與形容詞應答

詢問天氣最常用的兩大問句為「What is the weather like in + 地點?」與「How is the weather in + 地點?」。特別注意 What 必須搭配 like（like 為介系詞），而 How 絕不能接 like。
回答天氣時，最常用虛主詞 It 表自然現象：
• It is rainy / sunny / windy / cloudy / snowy today.
天氣形容詞大多由名詞加上 -y 形成：rain → rainy、sun → sunny（重複字尾）、cloud → cloudy、wind → windy、snow → snowy。

### 雨天與雪天四大神級換句結構

會考與段考最常考「下雨／下雪」的四種句型轉換，主詞與動詞搭配必須絕對精準：
1. 虛主詞 It 當主詞（動詞用 rain/snow）：It rains heavily in Taipei in winter.
2. 虛主詞 It 當主詞（形容詞 rainy/snowy）：It is very rainy in Taipei in winter.
3. 人類 We/They 當主詞（動詞用 have，搭配名詞 rain）：We have a lot of rain in Taipei in winter.
4. There is 存在句當主詞（搭配名詞 rain）：There is a lot of rain in Taipei in winter.
注意：rain 與 snow 當名詞時為不可數名詞，不可加 s，需用 much 或 a lot of 修飾；修飾動詞用副詞 heavily，修飾名詞則用形容詞 heavy/a lot of。

### 換句秒殺心法

```text
天氣換句速記口訣：
It rain 動詞加副詞；It is rainy 形容詞；
We have rain 用名詞；There is rain 不可數！
```
